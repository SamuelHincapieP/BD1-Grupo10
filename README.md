# Tarea 6 - Red Social Estudiantil Pascualina

Este repositorio contiene los archivos de la Tarea 6 de Bases de Datos.

## Estructura

- `tarea6/sql/crear_tablas.txt`: script DDL con las tablas, relaciones y restricciones.
- `tarea6/sql/consultas.txt`: las 14 consultas ejecutadas en PostgreSQL.
- `tarea6/sql/optimizacion.txt`: índices y consultas `EXPLAIN ANALYZE`.
- `tarea6/video/`: carpeta reservada para el video de sustentación.

## Ejecución recomendada

1. Abra pgAdmin y cree o seleccione la base de datos del proyecto.
2. Ejecute `crear_tablas.txt`.
3. Inserte los datos de prueba usados durante la actividad.
4. Ejecute las consultas de `consultas.txt`.
5. Ejecute las sentencias de `optimizacion.txt` solo después de contar con datos cargados.

No se incluyeron capturas ni evidencias gráficas en este repositorio.
